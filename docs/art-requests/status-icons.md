# 상태이상 아이콘 6종 — 에셋 요청 (Codex)

배경: 직업 시너지 개편(`docs/card-synergy-design-v01.md`)으로 적·전사 머리 위에 **쌓이는 상태**가 칩으로 뜬다.
지금 칩 안의 그림은 엔진이 벡터로 임시로 그린다(`godot/dungeon/view/status_chip.gd` `_glyph`).
카드 프레임의 손그림 톤에 맞는 정식 아이콘으로 바꾼다.

참고 화면: `godot/screenshots/capture/status_all.png` (머리 위 둥근 칩 = 지금의 임시 그림)
참고 톤: `godot/assets/cards/stone_wall.png` (굵은 검정 외곽선, 손그림, 겨울 숲 원정대), `godot/assets/ui/cost_badge/` (작게 줄여도 읽히는 메달)

## 쓰임 (엔진이 하는 것 / 에셋이 하는 것)
- 엔진이 그린다: 칩의 **둥근 바탕(짙은 남보라) + 상태 색 테두리 + 오른쪽 아래 숫자**(쌓인 수), 값이 오를 때 튕기는 연출.
- 에셋은 **가운데 그림(글리프)만** 담는다. 바탕 원·테두리·숫자는 넣지 않는다.
- 화면 크기: 칩 지름 34px, 그림은 칩 안쪽 28px 정도로 그려진다 → **28px 로 줄였을 때 실루엣이 한눈에 읽혀야 한다.**
- 오른쪽 아래 1/4 은 숫자가 덮는다 → 그림의 중요한 부분은 가운데~왼쪽 위에 둔다.

## 산출물 (모두 128×128, 투명 배경 RGBA PNG, 그림은 가운데 지름 약 104px 원 안)
저장 위치: `godot/assets/ui/status/` — 파일이 생기면 엔진이 자동으로 벡터 그림 대신 쓴다(코드 수정 불필요).

| 파일 | 상태 | 칩 테두리 색(엔진) | 그림 방향 |
|---|---|---|---|
| `status_mark.png` | 표식(사냥감) — 받는 피해 +N | 붉은색 #FF4538 | 붉은 조준경/과녁. 동심원 + 네 갈래 눈금 + 가운데 점. 화살이 꽂힌 과녁도 좋음 |
| `status_burn.png` | 화상 — 적 턴마다 N 피해 | 주황 #FF8C1F | 주황·노랑 2톤 불꽃. 끝이 살짝 휘어 일렁이는 느낌 |
| `status_chill.png` | 냉기 — 3 쌓이면 빙결 | 하늘색 #8CD9FF | 여섯 갈래 눈송이(가지 있는 결정). 하늘색 + 흰 하이라이트 |
| `status_freeze.png` | 빙결 — 다음 적 턴 행동 불가 | 연청 #B3F2FF | 각진 얼음 덩어리/육각 결정 안에 갇힌 느낌. 금 간 흰 하이라이트 |
| `status_fury.png` | 투지(전사) — 전사 카드 피해 +N | 붉은색 #FF4030 | 붉은 세 줄 발톱 자국 또는 불타는 주먹. 공격적이고 뜨거운 느낌 |
| `status_taunt.png` | 도발 — 적이 전사를 노림 | 주황 #FF9E33 | 나무 방패(가운데 쇠 장식) + 작은 느낌표 |

공통
- 굵은 검정 외곽선(28px 축소 시 1~1.5px 남을 두께), 손그림 채색, 그림자 없음 또는 아주 약하게.
- 상태 색이 그림의 주색이 되게(칩 테두리와 같은 계열). 여섯 개가 나란히 있어도 **색과 실루엣만으로** 서로 구분돼야 한다.
- 이미지 생성 결과에 배경이 있으면 Python(PIL 등)으로 배경 제거·128 캔버스 가운데 정렬까지 처리해 깨끗한 알파로. 가장자리 헤일로 금지.
