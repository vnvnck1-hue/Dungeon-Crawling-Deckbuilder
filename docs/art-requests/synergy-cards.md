# 직업 시너지 신규 카드 전용 원화 27장 — 에셋 요청 (Codex)

배경: 직업 시너지 개편(`docs/card-synergy-design-v01.md`)으로 카드가 24장 → 50장이 됐다(생성 카드 포함).
새 카드 27장은 지금 마녀산장 원화를 **임시로** 빌려 쓴다(`godot/dungeon/data/defs.gd` 각 카드의 `art`).
카드마다 내용에 맞는 전용 원화를 만든다.

## 형식 — 기존 카드와 똑같이
- 기준 카드: `godot/assets/cards/stone_wall.png`, `godot/assets/cards/frost_rune.png`, `godot/assets/cards/hunter.png` (1024×1536)
- **프레임·판 배치는 기준 카드와 픽셀 단위로 같게**: 위쪽 제목 리본, 그 아래 분류 띠, 가운데 그림 창, 아래 크림색 양피지 규칙 판, 보라색 바깥 테두리, 나무 기둥·박공 지붕, 눈 덮인 솔가지·주황 열매 장식.
  엔진(`scripts/ui/card_face.gd`)이 제목은 y 60 부근(가로 205~818), 규칙은 y 1164 부근(가로 106~916, 높이 296)에 글자를 굽는다 → 이 칸들은 **비워 둔다(글자 없음)**.
- 그림 창 안 일러스트만 카드마다 다르게. 손그림 + 굵은 검정 외곽선, 겨울 밤 숲 원정대 톤.
- 직업 색 액센트(그림 안 빛·소품 색으로 은근히): 전사 주황 #F28C52 · 궁수 초록 #73D973 · 마법사 보라 #B380FF.
  상태 색도 맞춘다: 표식 붉은색 · 화상 주황 · 냉기/빙결 하늘색 · 투지 진홍.
- 저장: `godot/assets/cards/synergy/<카드 id>.png` (1024×1536 PNG). 파일이 생기면 엔진이 자동으로 임시 원화 대신 쓴다(코드 수정 불필요).
