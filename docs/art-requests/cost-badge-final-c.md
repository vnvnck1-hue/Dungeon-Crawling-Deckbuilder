# 카드 행동력 배지 — C안(숲 보석 메달) 최종 에셋 요청

확정 시안: `art/concepts/cost-badge/concept-c.png` (C — Woodland Gem Seal)
배경 요청서: `docs/art-requests/cost-badge-concepts.md`

## 쓰임
- 손패 카드(폭 약 110px) 왼쪽 위 모서리에 34~40px 크기로 얹힌다.
- 숫자는 엔진의 Label 로 얹는다 → **에셋에는 숫자를 넣지 않는다.**
- 보석 링은 엔진 셰이더가 영웅색(전사 #F28C52 / 궁수 #73D973 / 마법사 #B380FF)으로 물들이고
  천천히 은은하게 반짝이게 한다 → **보석 링 레이어는 무채색(밝은 회색~흰색 명암)** 으로 만든다.
- 행동력 부족(비활성)은 엔진이 채도·밝기를 낮춰 표현한다(별도 에셋 불필요).

## 가장 중요한 조건 — 카드 이름을 가리지 않을 것
- 실루엣은 **거의 원형**으로 압축한다. 시안의 솔가지·열매 장식이 오른쪽/위로 넓게 뻗어 카드 제목 띠를
  덮지 않게, 장식은 원 바깥으로 최대 캔버스의 6% 이내만 삐져나오게 한다.
- 눈은 원 윗부분 테두리에 얇게 얹고, 밧줄은 왼쪽 아래에 작게. 솔가지·열매는 왼쪽 위에 한 줌만(또는 생략).
  오른쪽(제목 쪽)으로 뻗는 장식은 두지 않는다.
- 34px 로 줄였을 때 "나무 고리 + 색 보석 링 + 어두운 중앙"이 한눈에 읽혀야 한다. 굵은 검정 외곽선 유지.

## 산출물 (모두 같은 캔버스 256×256, 투명 배경 RGBA PNG, 원 중심 = 캔버스 중심)
저장 위치: `godot/assets/ui/cost_badge/`
1. `badge_face.png` — 중앙 어두운 면(숫자 받침). 단색에 가까운 짙은 남보라~숯색, 은은한 안쪽 그림자 정도.
2. `badge_gem.png` — 보석 링만. **무채색(회색조)** 으로 패싯 명암을 살린다(밝은 면 거의 흰색, 어두운 면 중간 회색).
   중앙은 투명. 링 바깥/안쪽 경계는 face·frame 과 살짝 겹치게.
3. `badge_frame.png` — 나무 고리 + 눈 + 밧줄 + (작은) 솔가지, 굵은 검정 외곽선 포함. 중앙(보석·face 자리)은 투명.
4. `badge_preview.png` — 위 세 장을 face → gem(마법사 보라로 임시 착색) → frame 순서로 합성하고 숫자 2를 얹은
   확인용 미리보기(엔진에서는 쓰지 않음). 가능하면 34px 축소본도 옆에 붙여 줘.

세 레이어는 정확히 겹쳐야 한다(같은 캔버스·같은 중심). 이미지 생성 결과에 배경이 있으면
Python(PIL 등)으로 배경 제거·레이어 분리·256 캔버스 정렬까지 처리해서 깨끗한 알파로 만들어 줘.
가장자리에 배경색 테두리(헤일로)가 남지 않게 한다.

## 하지 말 것
- `godot/` 아래 `.gd`·`.tscn`·셰이더 수정 금지(엔진 적용은 별도 작업).
- 숫자·텍스트를 에셋에 넣지 말 것(미리보기 제외).
- 작업 끝에 `godot/assets/ui/cost_badge/README.md` 에 레이어 구성·실루엣 반경(px, 256 기준)·
  보석 링의 안쪽/바깥 반경(px)을 적어 줘. 엔진 셰이더가 이 값을 쓴다.
