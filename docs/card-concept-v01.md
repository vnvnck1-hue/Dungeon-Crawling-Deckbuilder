# 숲길 원정대 — 카드 컨셉 v01 (2026-10-26, 2026-10-27 개정)

마녀산장(witchs-lodge)의 눈 덮인 숲 프랍·툰 화면·카드 연출을 그대로 가져온 **그리드 기반 던전 크롤러 카드 게임** 프로토타입.
이 문서는 궁수·전사·마법사의 시작 카드 9장과 레벨업 카드 15장, 그 카드를 받치는 전투 규칙을 정한다. 수치는 프로토타입 시작값이며 플레이해 보며 고친다.

> **카드 목록·상태 규칙은 [card-synergy-design-v01.md](card-synergy-design-v01.md) 가 최신이다(2026-10-27 직업 시너지 개편: 카드 50장, 표식 중첩·냉기·화상·투지, 연계).** 아래 §3 카드 표는 개편 전 기록.

> 2026-10-27 개정: 적도 이동 없음 · 행동력 매 턴 3 · 손패 5장(덱을 섞어 뽑기) · 경험치·레벨업 카드 · 전투 줌 · 피격 타격감 · 전체 화면.

## 1. 한 판의 흐름

1. **원정대 고르기** — 궁수·전사·마법사 중 셋을 고른다(지금은 셋뿐이라 셋 모두).
2. **방(스테이지)** — 숲속 공터 하나가 한 방이다. 롤토체스처럼 **아군 지역(왼쪽 아래 4열)** 과 **적 지역(오른쪽 위 4열)** 으로 나뉜 4행 × 8열 격자.
   전장은 칼바람 나락처럼 화면에 사선으로 놓이고, 카메라는 살짝 사선 위에서 내려다보는 쿼터뷰.
3. **적 전멸 → 자동 이동** — 방의 적이 모두 쓰러지면 원정대가 **좁은 숲길을 줄지어 걸어** 다음 방으로 간다. 방과 방은 비교적 좁은 길로만 이어진다.
4. **세 무리를 처치할 때마다 덩치 큰 중간 보스**(4번째 방 달빛 늑대인간, 8번째 방 오크 족장). 8번째 방을 넘기면 승리, 원정대가 모두 쓰러지면 패배.
5. 방 사이는 뛰어서 이동한다(정리 연출 포함 약 4.4초).

## 2. 행동력·손패 규칙

| 항목 | 규칙 |
|---|---|
| 행동력 | 캐릭터마다 따로. **매 아군 턴 3으로 가득 찬다**(방·턴 번호와 무관) |
| 남은 행동력 | 다음 턴으로 넘어가지 않는다 |
| 카드 비용 | 기본 공격 1 · 주 스킬 2 · 궁극기 3. 레벨업 카드도 1~3 |
| 덱 | 캐릭터마다 덱(시작 3장 + 레벨업으로 고른 카드, 같은 카드 여럿 가능) |
| 손패 | **5장.** 방에 들어서면 살아 있는 캐릭터의 덱을 모두 섞어 뽑을 패를 만들고 5장 뽑는다. 아군 턴마다 5장이 될 때까지 다시 뽑는다 |
| 버림패 | 쓴 카드는 타오르며 버림패로 간다. 뽑을 패가 비면 버림패를 섞어 뽑을 패로. 쓰러진 동료의 카드는 뽑지 않는다 |
| 적 턴 | **모든 아군의 행동력이 0이 되면** 자동으로 적 턴. 아니면 [턴 종료] 버튼 |
| 이동 | **아군·적 모두 없음.** 근접 카드를 쓰면 대상 적 앞까지 순식간에 돌진해 치고 돌아온다. 원거리 카드는 그 자리에서 쏜다. 적도 자기 칸에서 바로 아군을 친다(근접은 돌진) |
| 강조 | 카드를 집어 올리면 그 카드 주인과 대상이 될 수 있는 적만 남기고 전장·숲·다른 동료·다른 캐릭터 카드가 어두워진다 |
| 방어 | 받는 피해를 먼저 막는다. 다음 아군 턴이 시작되면 사라진다 |

### 경험치·레벨업

| 항목 | 규칙 |
|---|---|
| 경험치 | 적이 쓰러지면 **살아 있는 아군 모두** 그 적의 경험치(졸개·투척꾼 4, 도끼잡이 7, 늑대인간 20, 족장 25)를 얻는다. **직접 처치한 캐릭터는 +3** |
| 레벨 | 다음 레벨까지 `6 + 6 × 레벨`(1→2: 12, 2→3: 18, 3→4: 24 …). 한 판에 캐릭터마다 대략 5번 |
| 레벨업 | 그 캐릭터의 **레벨업 카드 셋(pool) 중 셋을 보여 주고 하나를 고른다.** 고른 카드는 덱에 들어가고, 전투 중이면 뽑을 패에도 바로 섞인다. 같은 카드를 또 골라도 된다 |
| 시점 | 카드·적 턴 연출이 끝난 직후(여럿이면 차례로). 전멸했으면 건너뛴다 |

### 화면·타격감

- 전투 중 카메라가 더 당겨져(세로 시야 15.2 m → 13.2 m) 캐릭터가 크게 보이고, 행군 때 다시 넓어진다.
- 피격: 움찔(RigAnim flinch) + 자세 얼림 + 하얗게 번쩍(`hit_flash`) + 납작 스쿼시 + 때린 쪽 반대로 넉백(스프링 복귀) + 발밑 눈가루 + **히트스탑**(시간 배율 0.04, 0.06~0.14초) + 화면 흔들림. 최대 체력 대비 피해가 클수록, 처치면 더 세게.
- 처음 실행하면 테두리 없는 전체 화면(마녀산장 `window_mode.gd`), F11 로 전환.

### 사거리·격자 용어

- **근접(돌진)**: 적 지역 어느 적이든 고를 수 있고, 시전자가 그 적 앞까지 달려가 친다.
- **원거리**: 적 지역 어디든.
- **표식(사냥감)**: 표식이 붙은 적은 받는 피해 +3. 다음 아군 턴이 끝날 때까지.
- **빙결**: 다음 적 턴에 아무것도 못 한다.
- **도발**: 다음 적 턴에 모든 적이 도발한 아군을 노린다.

## 5. 마녀산장에서 그대로 가져온 것

- 숲: 눈 침엽수 3종·묘목·고사목·바위 무리·덤불·고사리·버섯 Tripo 프랍과 nature/painted 셰이더
- 지면: 붓터치 눈·숲길·숲바닥 텍스처와 무작위 회전 패치 기법(던전용 지면 셰이더로 파생)
- 화면: ScreenStyle "강렬한 툰 · 심야", 툰 외곽선·후처리(post_grade)·색 웅덩이 조명·지면 안개(ground_haze)
- 환경: 공기 원근(AerialPerspective — 깊이 안개와 주변 불빛 색이 번지는 공기), 날씨(WeatherVfx — 돌풍·눈보라·바람 줄기·나뭇잎·나무에서 털리는 눈, 보스 방은 밤 눈보라), 입김(BreathVapor), 눈 위 발자국
- 캐릭터: Tripo 파츠 묶음 모델 + RigAnim(걷기·베기·활 당기기·시전·움찔), 용병의 활·검·방패 소품
- 카드: card_view(스프링·휨·뽑기 회전·보여 주고 타오르기·재 입자), card_burn/glow 셰이더, CardFace 글자 굽기(BM 을지로체)
- 연출: VfxPool 카툰 입자, Fx(타격·베기·폭발·피해 숫자), 번개 창(LightningVfx), 서리 룬(FrostRuneVfx), 리본 꼬리, 효과음 뱅크
